# Day-07 – Python OOP Practice

This project contains my Day-07 Python practice programs focused on **Object-Oriented Programming (OOP)**.

## Topics Covered

### 1. Creating and Using Classes

* Creating classes using the `class` keyword
* Using the `__init__()` constructor
* Defining attributes
* Defining methods
* Using `self`
* Creating objects (instances) from classes

### 2. Working with Multiple Instances

The project demonstrates how to create multiple objects from the same class.

Examples include:

* `Dog` class
* `Student` class
* Creating multiple student and dog objects
* Calling methods for individual objects

### 3. Restaurant Class

A `Restaurant` class is created to practice:

* Restaurant name
* Cuisine type
* `describe_restaurant()` method
* `open_restaurant()` method
* Creating multiple restaurant instances

### 4. User Class

A `User` class is used to practice:

* User first and last names
* User information
* `describe_user()` method
* `greet_user()` method
* Creating multiple user instances

### 5. Working with Classes and Instances

The project includes a `Car` class demonstrating:

* Make
* Model
* Year
* Odometer reading
* Instance methods
* Returning formatted information from a method

### 6. Login Attempts

The `User` class is extended to manage login attempts.

Features include:

* Tracking login attempts
* Incrementing login attempts
* Resetting login attempts
* Using a `while` loop
* Taking user input
* Creating a simple menu-driven program

## Practice Exercises

The project includes exercises based on:

* Creating a `Restaurant` class
* Creating a `User` class
* Creating multiple instances
* Creating a `Car` class
* Managing user login attempts

## How to Run

Make sure Python is installed on your system.

Run the program using:

```bash
python main.py
```

Some sections of the program require user input through the terminal.
