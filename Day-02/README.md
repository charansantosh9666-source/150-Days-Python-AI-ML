## 💻 Coding Tasks

### 1. Student Marks Program

A program that calculates the average marks of students and assigns a grade based on the following criteria:

| Average Marks | Grade |
| ------------- | ----- |
| 90–100        | A     |
| 80–89         | B     |
| 70–79         | C     |
| 60–69         | D     |
| Below 60      | F     |

Example:

```text
Marks = [88, 76, 90, 69, 95]

Average = 83.6
Grade = B
```

### 2. Remove Duplicates from a List

The program demonstrates two approaches to removing duplicate values:

* Preserving the original order using a loop and `set`
* Removing duplicates using a `set`

Example:

```text
Input:  [1, 5, 2, 2, 3, 1, 4]
Output: [1, 5, 2, 3, 4]
```

### 3. Simple Student Database

A basic student database implemented using a Python dictionary.

It demonstrates:

* Adding student records
* Searching for a student
* Updating student marks
* Deleting a student record

Example student record:

```python
{
    1: {
        "name": "charan",
        "marks": 95
    }
}
```
