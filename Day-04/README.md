### 🔥 Example

```python
# Multiples of 3 from 3 to 30
numbers = [x for x in range(3, 31) if x % 3 == 0]
print(numbers)
```

Output:

```text
[3, 6, 9, 12, 15, 18, 21, 24, 27, 30]
```
