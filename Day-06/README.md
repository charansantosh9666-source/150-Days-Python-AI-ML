# Day-06 – Python Practice

This project contains my Day-06 Python practice programs.
The main topics covered are **Dictionaries** and **Functions**.

## Topics Covered

### 1. Dictionaries

* Creating an empty dictionary
* Adding key-value pairs
* Updating dictionary values
* Deleting dictionary keys
* Creating dictionaries using lists
* Counting elements using dictionaries
* Accessing values using `get()`
* Using dictionaries to store information about people
* Storing and displaying people's favorite numbers
* Working with a list of dictionaries

### 2. Functions

* Defining and calling functions
* Passing arguments to functions
* Using default parameters
* Returning and working with dictionary data
* Creating functions for reusable tasks
* Taking user input inside functions
* Using functions with `while` loops
* Building a simple album management program

## Practice Exercises

The `main.py` file includes practice exercises such as:

1. Storing and searching personal information using dictionaries
2. Storing people's favorite numbers
3. Working with multiple person dictionaries
4. Creating and calling functions
5. Describing cities using function parameters
6. Creating album dictionaries using functions
7. Taking album information from the user using a `while` loop
8. Displaying and managing album information through a menu

## How to Run

Make sure Python is installed on your system.

Run the program using:

```bash
python main.py
```

The program contains interactive sections, so follow the instructions displayed in the terminal.
